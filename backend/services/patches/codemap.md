# backend/services/patches/

## Responsibility

Vendored-upstream monkey-patches and a torch-side GGUF dequantizer. Each module is imported for its side effects (patch application happens at import time, guarded by idempotency flags). All patches target the external `ltx_core` / `ltx_pipelines` packages (git deps from Lightricks/LTX-2, declared in `backend/pyproject.toml`) and are meant to be deleted once upstream ships the fix. No Protocols or service wiring live here — this is purely runtime behavior modification of the model-loading and layer-streaming stack.

Files:

- `gguf_loader_fix.py` — GGUF state-dict loader, lazy-dequant `nn.Linear` swap-in, GGUF sd_ops, runtime LoRA attach, llama.cpp prompt-enhancement wiring, Kijai FP8-scaled linear, and the public `install_gguf_*` entry points.
- `gguf_torch_dequant.py` — pure-torch dequant for Q4_K / Q5_K / Q6_K blocks; called from `QParam.dequant()` on CUDA.
- `pinned_pool_fix.py` — replaces `ltx_core.layer_streaming._LayerStore` with on-demand pinned-memory pooling. No-ops (skips patch application, logs info) when upstream no longer exposes `ltx_core.layer_streaming`, so the module imports cleanly without the vendored package present.
- `record_stream_fix.py` — replaces `LayerStreamingWrapper._register_hooks`/`teardown` to drop `record_stream` (CUDA allocator corruption on RTX 5090 / CUDA 12.8 / PyTorch 2.10) in favor of manual GPU-ref + event tracking. No-ops (skips patch application, logs info) when upstream no longer exposes `ltx_core.layer_streaming`, so the module imports cleanly without the vendored package present.
- `safetensors_loader_fix.py` — replaces `SafetensorsStateDictLoader.load` with a Python `mmap` + `torch.frombuffer` loader (Windows access-violation fix).
- `safetensors_metadata_fix.py` — replaces four metadata readers (`SafetensorsModelStateDictLoader.metadata`, the `ltx_pipelines.ic_lora` reference-downscale reader, `ltx_pipelines.utils.constants.detect_params`, `services.text_encoder.ltx_text_encoder.LTXTextEncoder.get_model_id_from_checkpoint`) with direct header reads (avoids commit-charge reservation). The ic_lora downscale subpatch supports both the current public `read_lora_reference_downscale_factor` and the legacy private `_read_lora_reference_downscale_factor` (preferring the public name); if neither symbol exists it logs a warning and skips only that subpatch instead of crashing startup.

## Design Patterns

- **Import-time patch application with idempotency guards.** Each module assigns replacement functions onto upstream symbols at module bottom (`_LayerStore.__init__ = _patched_init`, etc.) and asserts the target attribute exists first (so an upstream rename fails loudly instead of silently regressing). Method-rebinding patches use a `_ltx_desktop_*_patch = True` sentinel attribute on the replacement to short-circuit re-application (e.g. `install_gguf_prompt_encoder_patch`, `_install_gemma_encode_patch`, `_install_llama_cpp_*`).
- **`__class__` reassignment over wrapping.** `GgufLinear` / `KijaiFp8ScaledLinear` are installed by mutating `module.__class__` on existing `nn.Linear` instances (`_amend_forward_with_gguf`, `_amend_forward_with_kijai_fp8_scaled`) — mirrors upstream `fp8_cast.Fp8CastLinear`. Exposes them as `ltx_core.loader.module_ops.ModuleOps` (`GGUF_DEQUANT_LINEAR_OP`, `GGUF_EMBEDDINGS_DEQUANT_LINEAR_OP`, `GGUF_GEMMA_DEQUANT_LINEAR_OP`, `GGUF_GEMMA_TEXT_ONLY_OP`, `KIJAI_FP8_SCALED_LINEAR_OP`) so builders compose them via the standard module-op pipeline.
- **Lazy dequant via Parameter subclass.** `QParam(torch.nn.Parameter)` stores raw quantized bytes in `_raw` and a shape-`(0,)` float placeholder as the parameter data — so `.to(device)` is cheap and never copies quantized bytes; the full fp weight is materialized per-forward inside `GgufLinear.forward` via `dequant()`. `_load_from_state_dict` is overridden to assign `QParam`s directly, bypassing the default shape check that the placeholder would trip.
- **`StateDictLoader` duck-typing.** `GgufStateDictLoader` implements `metadata(path)` + `load(path, sd_ops, device)` to satisfy `ltx_core.loader.primitives.StateDictLoader` structurally; no inheritance.
- **SDOps strategy objects.** `GgufNativeSDOps`, `GgufGemmaSDOps`, `GgufEmbeddingsProcessorSDOps`, and `KIJAI_VIDEO_VAE_*_KEYS_FILTER` (built via `SDOps(...).with_matching(...).with_replacement(...)`) remap/filter tensor keys during load; each implements `apply_to_key` + `apply_to_key_value`.
- **One-shot global LoRA-build patch.** `_patch_gguf_lora_build()` flips a module-level `_GGUF_BUILD_PATCHED` flag and wraps `SingleGPUModelBuilder.build` to preload LoRA safetensors, run the upstream build with `loras=()`, then attach `lora_pairs` to `GgufLinear` modules post-load.

## Data & Control Flow

**GGUF loader entry (`install_gguf_loader`, `gguf_loader_fix.py:1128`):** iterates `pipeline.{stage,stage_1,stage_2}._transformer_builder`; for each, rebuilds the builder via `_replace_builder` (a local helper in `gguf_loader_fix.py`) with `model_loader=GgufStateDictLoader(allow_safetensors_only=True, keep_raw_on_cpu=<VRAM policy>)` (raw GGUF bytes CPU-resident unless the per-run **effective** VRAM tier from `services.local_memory_plan.snapshot_vram` (reserve 2 GiB) is ≥28 GiB, or `LTX_GGUF_KEEP_RAW_ON_GPU=1` forces GPU residency to avoid repeated CPU→GPU copies; `LTX_GGUF_KEEP_RAW_ON_CPU=1` forces CPU; dequant stays per forward inside `GgufLinear`), `model_sd_ops=GgufNativeSDOps()`, and `module_ops` augmented with `GGUF_DEQUANT_LINEAR_OP`. `_replace_builder` does NOT assume a dataclass: upstream `SingleGPUModelBuilder` exposes `with_*` copy-methods for `model_sd_ops`/`module_ops`/`loras`/`registry`/`lora_load_device`/`fuse_rule`, while `model_path`/`model_loader` are read-only properties backed by private `_model_path`/`_model_loader` attrs — the helper shallow-copies (`copy.copy`) and sets those private attrs. If `replaced.loras` has any non-zero strength, calls `_patch_gguf_lora_build()` first. Raises `RuntimeError` if no stage has a `_transformer_builder`. **Forces each recognized stage to `OffloadMode.NONE` and clears `_streaming_builder`** (even on the idempotent already-installed branch and even if the pipeline was built with CPU/DISK offload) — true GGUF `StreamingModelBuilder` is unsupported (upstream streaming scans safetensors; lazy GGUF `QParam` blocks cannot be streamed by that path), so GGUF stages must full-load via `_transformer_builder`.

**Kijai/split V2 config patch (`install_kijai_transformer_config_patch`):** for safetensors-only split tuples, repoints both `_transformer_builder` AND `_streaming_builder` (when present) on each `stage`/`stage_1`/`stage_2` to a V2-config loader (full config lives in the text-projection sidecar metadata, not the first shard). Shared by fast video / IC-LoRA / A2V / retake / HDR, so split-safetensors CPU-offload paths stream with the correct V2 config. Skips GGUF tuples and single-string monolith paths.

**GGUF tensor load (`GgufStateDictLoader.load`, `:614`):** splits incoming paths into `.gguf` and `.safetensors`; resolves `target_device` (GPU unless the loader was built with `keep_raw_on_cpu=True` or env `LTX_GGUF_KEEP_RAW_ON_CPU=1`). Per tensor: quantized types → `QParam(raw, tensor_type, name, device=target_device)` when `lazy_quantized` and filter matches (Gemma filter is `_is_gemma_linear_name` matching `blk.N.<GEMMA_LINEAR_WHITELIST suffix>`); otherwise eager `gguf.quants.dequantize(...)` → bf16 tensor on `target_device`. `add_value()` runs `_apply_sd_ops(name, tensor_t, sd_ops)` and accumulates into a `StateDict(sd, device, size, dtype)`. Empty-state-dict guard raises (prevents silent garbage from a Comfy-prefix sd_ops filtering all native-named tensors).

**Per-forward dequant (`GgufLinear.forward`, `:206`):** if `self.weight` is `QParam`, `weight = weight.dequant(device=input.device, dtype=compute_dtype)`. `QParam.dequant()` (`:142`) tries `dequantize_gguf_tensor_torch()` first on CUDA (Q4_K/Q5_K/Q6_K only, else returns `None` → falls back to `gguf.quants.dequantize` on CPU numpy). Optional `torch.cuda.empty_cache()` gated by `LTX_GGUF_EMPTY_CACHE_EACH_FORWARD=1`. Then applies any `lora_pairs` (`(lora_A, lora_B, strength)` tuples) via two `F.linear` calls.

**llama.cpp prompt enhancement:** two routes — `_install_llama_cpp_enhance_patch()` swaps `GemmaTextEncoder._enhance` to call `Llama(model_path, n_gpu_layers=-1, ...)`; `_install_llama_cpp_prompt_encoder_call_patch()` swaps `PromptEncoder.__call__` to run `_enhance_prompt_with_llama_cpp()` standalone *before* the dense PyTorch Gemma builds, then re-enters the original call with `enhance_first_prompt=False`. Both `gc.collect()` + `torch.cuda.empty_cache()` in `finally`.

**`pinned_pool_fix`:** `_patched_init` stores `_source_data` (original CPU tensors) per layer + `_pinned_in_flight` dict; `_patched_move_to_gpu` pins via `source[name].pin_memory()`, transfers `non_blocking`, keeps pinned refs alive in `_pinned_in_flight[idx]`; `_patched_evict_to_cpu` restores `param.data = source[name]` and pops in-flight refs; `_patched_cleanup` clears both.

**`record_stream_fix`:** `_patched_register_hooks` holds `gpu_refs[idx]` (param/buffer data list) in `_pre_hook` and records a per-layer `torch.cuda.Event` in `_post_hook`; `_drain_completed_refs()` polls `event.query()` and releases refs for completed layers. `_patched_teardown` syncs + clears refs before delegating to original teardown.

**`safetensors_loader_fix._patched_load`:** opens each shard via `mmap.mmap(...)` + `memoryview`, parses the 8-byte LE header-size + JSON header, then `torch.frombuffer(mv_data[start:end], dtype=_DTYPES[...]).reshape(shape)`; attaches `(mm, mv, mv_data, f)` to `tensor.untyped_storage()._ltx_tensor_mmap_refs` so the mapping outlives the tensor. Applies `sd_ops.apply_to_key` / `apply_to_key_value`.

**`safetensors_metadata_fix._read_safetensors_metadata`:** `open(path,"rb")` → `struct.unpack("<Q", read(8))` → `json.loads(read(header_size))` → `header.get("__metadata__")`; no mmap, no commit charge. Four upstream call sites rebound to use it.

## Integration Points

- **Consumed by pipeline constructors** — `install_gguf_loader`, `install_gguf_prompt_encoder_patch`, `install_gguf_t2v_conditioning_patch`, `install_gguf_component_paths` are invoked during `DistilledPipeline`/`DistilledNativePipeline` build for GGUF profiles (see `services/fast_video_pipeline/`, `services/ic_lora_pipeline/`, `services/a2v_pipeline/`, `services/retake_pipeline/`). `install_gguf_component_paths` also routes explicit `video_vae_path`/`audio_vae_path` from `ResolvedLtxComponents` (see `services/ltx_components.py`) into conditioner/decoder/vocoder builders.
- **`gguf_torch_dequant.dequantize_gguf_tensor_torch`** ← `QParam.dequant()` (`gguf_loader_fix.py:146`); CUDA fast-path only.
- **`safetensors_metadata_fix` patches `services.text_encoder.ltx_text_encoder.LTXTextEncoder.get_model_id_from_checkpoint`** — couples this folder to `services/text_encoder/`.
- **External surface:** all rebind targets live in vendored `ltx_core` (`loader.sft_loader`, `loader.single_gpu_model_builder`, `layer_streaming`, `model.transformer.model.LTXModel`, `text_encoders.gemma.*`) and `ltx_pipelines` (`utils.blocks`, `utils.constants`, `ic_lora`), installed from `Lightricks/LTX-2` per `backend/pyproject.toml`.
- **Not wired through `ServiceBundle` / Protocols** — patches are not service-injected; they mutate global upstream state and must be imported before the patched code path runs. No encode-path involvement (these patches concern model *loading* and layer *streaming*, not frame encoding).
